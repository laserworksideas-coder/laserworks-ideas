# Laserworks Ideas Website

## Add your photos
Put your product photos inside the `images` folder and name them:
- product-1.jpg
- product-2.jpg
- product-3.jpg
- product-4.jpg
- product-5.jpg
- product-6.jpg

You can also edit `index.html` later to add more products.

## Netlify
Upload the whole `laserworks-ideas-site` folder (or the ZIP) to Netlify's deploy area.
No build command is required.
